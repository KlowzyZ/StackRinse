# Security

A scan report can reveal usernames, project names and directory structure. Replace identifying paths with a minimal temporary fixture before sharing logs or screenshots.

Report vulnerabilities using [private vulnerability reporting](https://github.com/KlowzyZ/StackRinse/security/advisories/new) when available. If the repository has private reporting disabled, open a public issue asking the maintainer to enable a private channel. Keep sensitive reproduction details private until a fix is available.

Treat a suggestion to remove source, a boundary-crossing traversal, an unexpected filesystem write, or disclosure of a local inventory as a security issue. Include the StackRinse revision, operating system, filesystem type, entry point and expected boundary. Reproduce only with disposable data.
