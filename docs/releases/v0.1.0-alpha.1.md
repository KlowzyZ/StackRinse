StackRinse is an open-source developer storage workbench by KLOWZY. Scan a workspace to see where dependencies, build outputs and caches accumulate, then inspect the evidence behind each result.

**This alpha supports read-only discovery and dry-run review only. Actual cleanup, quarantine, restoration and permanent deletion are unavailable.**

## What you can do

- Browse projects and break down observed logical bytes by ecosystem or artifact type. See reviewable and protected totals and inspect detection evidence, rebuild implications and exact dry-run paths.
- Save scans on your device and compare complete inventories with matching roots, scan preferences and discovery rules.
- Export current or saved inventory to JSON or CSV through a native Save dialog.

StackRinse recognizes supported project-local layouts for Node.js (including Next.js and Nuxt), Python (including pytest, Ruff and mypy), Rust, Go, CMake, Godot 4, .NET, Maven, Gradle, Dart Pub and PHP Composer. [Ecosystem coverage and marker requirements](https://github.com/KlowzyZ/StackRinse/blob/v0.1.0-alpha.1/docs/ecosystems.md)

## Run on Windows

1. Download `StackRinse-v0.1.0-alpha.1-Windows-x64-Portable.zip` and `SHA256SUMS.txt` from this release.
2. Verify the ZIP using `Get-FileHash -Algorithm SHA256 <path-to-zip>`, then extract it. `BUILD.txt` records the source commit and executable checksum.
3. On x64 Windows 10 or 11, ensure Microsoft Edge WebView2 Evergreen Runtime is installed. [WebView2 Evergreen download](https://developer.microsoft.com/microsoft-edge/webview2/)
4. Open `StackRinse.exe`. The executable is unsigned and may trigger a Windows reputation warning. Follow your organization's policy for unsigned apps.

No installer, Rust, Node.js, Cargo, Tauri, MSVC Build Tools or development server is required. Settings stay in the Windows per-user roaming app data folder and scan history stays in the per-user local app data folder. Moving the executable continues to use the same data for that user.

## Privacy and safety

Scans run locally in your selected roots with no StackRinse telemetry. Exclusions, project protections and filesystem and Git boundaries limit what appears in a dry run. Settings and scan history are stored locally. Exports can contain absolute filesystem paths, so review them before sharing. [Safety model](https://github.com/KlowzyZ/StackRinse/blob/v0.1.0-alpha.1/docs/safety.md)

## Known limitations

- Observed logical bytes are file lengths. Filesystem features such as compression, sparse files, hard links and shared blocks can change physical usage. Logical totals carry no guarantee of recoverable space.
- Discovery depends on recognized manifests and generated-artifact markers. Custom layouts, global caches and unsupported tools may be missed. Permissions or cancellation can produce partial inventories.
- Git is optional. StackRinse protects candidates in repositories when it cannot verify the Git index.
- The downloadable package targets Windows x64. Linux and macOS builds are available from source.
