# Roadmap

## Discovery and review

The shared scanner, CLI and desktop workbench support read-only discovery and dry-run review. CI compiles the native application and runs workspace tests on Linux, macOS and Windows.

The next milestone is a packaged read-only preview. Exercise native pickers, keyboard and screen-reader navigation, high-DPI displays, large inventories and cancellation on slow volumes. Record platform, filesystem, fixture size and observed gaps for each run.

## Safe cleaning

Start with one platform and a narrowly defined artifact class. Prove candidate identity and authorization across the entire operation. Add switched-ancestor, link, tracked and untracked content, concurrent rename, locked-file, crash and partial-operation fixtures before exposing an executor.

Add durable history, recoverable cleanup and verified recovery instructions first. Review permanent removal separately. Keep each unsupported mode unavailable on each platform until its safety tests pass.

## Release candidate

Measure traversal performance and memory on documented fixtures. Exercise packaged applications on Windows, macOS and Linux, including keyboard navigation, high-DPI and slow or inaccessible volumes. Validate dependency licenses, packaging, installation and upgrade behavior. Stable publication requires a maintainer decision.
